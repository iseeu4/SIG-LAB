# SIG-LAB
SIG-LAB Signalling System 7 (SS7) and SIGTRAN

<img width="770" height="335" alt="image" src="https://github.com/user-attachments/assets/f23c4af1-9f71-467c-81b6-3b119c0f986b" />

Requirements:
- Windows 10 or 11 required (the .py file in the installation folder also runs on Linux)

Main Features:
- Professional maintenance software for telecommunications professionals!
- Full access to the SS7 network included!
- Uses SS7 (SIGTRAN) to log into telecommunications networks worldwide; all you
  need is an internet connection
- Built-in IMSI catcher
- Easily intercept cell phone numbers on GSM networks
- Intercept OTPs (one-time passwords)
- Monitor message traffic
- Make calls or send messages from any number

Free to use!
